# Ecosystem Partners

Dated screening for Laurito Capital: who might take a property, which opportunities are in the workbook, and how accommodation is bought or leased. This is not credit approval and not an investment recommendation.

Four views, each with one job:

- **Counterparties.** One directory. Registered providers and charities, commercial operators, and other records each appear once. Top 10 sorts that directory.
- **Opportunities.** Workbook opportunities joined by opportunity ID, plus the official rent reference and a return check. Core scores are not recalculated while Score Breakdown dimensions are empty. Seed totals stay historical.
- **Frameworks.** How councils and government buy or lease accommodation.
- **Workbook.** Imported sheets behind the opportunity records. Snapshot imported 2026-10-20. v4 build 2026-11-03.

Ask Partners is the only assistant on this page. It searches those loaded files, cites the record, and can open the matching view. It does not invent names, financials or scores.

`partners.json`, `rp_charities.json`, `operators.json` and `frameworks.json` are published in this repository. The Analysis dashboard is a separate site: https://pgraham974.github.io/ecosystem-deals/
